# LPMQ Isep Misbah

Qur'an text in IQRO is sourced from EQuran.id/Kementerian Agama and rendered
with LPMQ Isep Misbah, the font created for Mushaf Al-Qur'an Standar Indonesia.
LPMQ documentation states that this font must be paired with the Mushaf Standar
Indonesia verse database.

- Official font page: https://lajnah.kemenag.go.id/info-lpmq/unduhan/quran-kemenag/font-lpmq-isep-misbah.html
- Official LPMQ description: https://lajnah.kemenag.go.id/info-lpmq/berita-dan-artikel/berita/produk-lpmq-yang-dipublish-dalam-quran-kemenag-2.html
